    Kernel gallery¶

    The same @parakeet.jit compiles broadcasting NumPy and explicit data-parallel operators. Use dsl.map when the inputs line up row by row, dsl.allpairs when every left row meets every right row, and dsl.fold when you can describe how two partial results combine. dsl.kernel is an alias for parakeet.jit.

    Start with one nearest-neighbor query, then change what the fold remembers. For a complete training program, try nanoGPT. The snippets come from executable examples. From an installed source checkout, run python -m examples.algebraic_gallery for the numerical checks.

    import numpy as np
import parakeet
from parakeet import dsl
from typing import NamedTuple

    The axis-fold examples below use the development version after 1.0.0. To run them, install the current checkout with python -m pip install -e ..

    Exact nearest neighbor¶

    Given Q query rows and R reference rows with the same feature count, return Q reference indices. For a query at 1 and references at 0, 2 and 4, the squared distances are [1, 1, 9]. The answer is index 0 because it is the first minimum.

    @parakeet.jit
def nearest_numpy(queries, references):
  delta = queries[:, None, :] - references[None, :, :]
  return np.argmin(np.sum(delta ** np.float32(2), axis=2), axis=1)

    For each query, map the same distance function over the references and return the position of its smallest value. The outer map repeats that search for every query.

    def squared_distance(query, reference):
  return np.sum((query - reference) ** np.float32(2))



@parakeet.jit
def exact_1nn(x_query, x_ref):
  """Exact nearest-neighbor index per query row."""

  def nearest_to(query):
    distances = dsl.map(lambda reference: squared_distance(query, reference), x_ref)
    return np.argmin(distances)

  return dsl.map(nearest_to, x_query)

    def squared_distance(query, reference):
  return np.sum((query - reference) ** np.float32(2))



class Winner(NamedTuple):
  distance: np.float32
  index: np.int64


def first_minimum(left, right):
  # Keep the first NaN. Among finite values, replace only on strict improvement.
  right_wins = np.isnan(right.distance) or right.distance < left.distance
  return right if right_wins and not np.isnan(left.distance) else left


@parakeet.jit
def nearest_fold(queries, references):
  scores = dsl.allpairs(squared_distance, queries, references)
  return dsl.fold(Winner, first_minimum, scores, axis=1, indexed=True, emit=lambda winner: winner.index)

    Read the explicit form from nearest_fold. allpairs defines a logical Q × R array of squared distances. Folding along axis=1 visits the references for one query. With indexed=True, Winner receives both the distance and its column index. Two adjacent groups can each report a winner. first_minimum keeps the left winner on ties and preserves the first NaN. Finally, emit extracts the index. This merge rule lets the compiler process tiles without storing the full distance matrix.

    With the axis-fold extension, both forms use the pairwise tile schedule on supported CPU, Metal and CUDA targets. The published 1.0.0 and post-release comparison used the nested-map spelling for the explicit implementation. Measured timings, allocations and revision details.

    Inverse-distance smoothing¶

    Keep the query/reference pairs and squared_distance from nearest neighbor. Now each reference carries a scalar observation. A point at squared distance d2 casts a vote with weight 1 / (1 + d2). To combine two groups, add their weight totals and their weighted observation totals. Divide once, after all groups have contributed. This implements a weighted mean for each query over a nonempty reference set.

    @parakeet.jit
def smooth_numpy(queries, references, observations):
  observations = observations.reshape(references.shape[0])
  delta = queries[:, None, :] - references[None, :, :]
  weights = 1 / (1 + np.sum(delta ** np.float32(2), axis=2))
  return np.sum(weights * observations, axis=1) / np.sum(weights, axis=1)

    def squared_distance(query, reference):
  return np.sum((query - reference) ** np.float32(2))



class WeightedSum(NamedTuple):
  weight: np.float32
  weighted_value: np.float32


def add_sums(left, right):
  return WeightedSum(left.weight + right.weight, left.weighted_value + right.weighted_value)


@parakeet.jit
def smooth_fold(queries, references, observations):
  values = observations.reshape(references.shape[0])
  scores = dsl.allpairs(squared_distance, queries, references)

  def contribution(distance_squared, ref_index):
    weight = 1 / (1 + distance_squared)
    return WeightedSum(weight, weight * values[ref_index])

  def weighted_mean(total):
    return total.weighted_value / total.weight

  return dsl.fold(contribution, add_sums, scores, axis=1, indexed=True, emit=weighted_mean)

    nanoGPT¶

    Train a two-layer transformer to predict the next character in a short text. The example builds token and position embeddings, applies two causal attention heads per layer, and trains the whole model with Adam. Run it from the source checkout. It prints the loss at steps 1, 20, 40 and 60 and checks that the final loss is below 80% of the initial loss.

    python -m examples.nanogpt

    For the text fragment para, the inputs are p a r and the targets are a r a. Within a sequence, the causal mask lets each position attend to itself and earlier characters. Across the batch, sequences are independent and share the same model parameters.

    tokens and targets both have shape (batch, context). Each call to loss_for_sequence gets one input row and its matching target row. dsl.map returns one loss per sequence. Their mean is the scalar used to train the model.

    def loss(params, tokens, targets, causal):
  def loss_for_sequence(input_ids, next_ids):
    return sequence_loss(params, input_ids, next_ids, causal)

  per_sequence = dsl.map(loss_for_sequence, tokens, targets)
  return np.mean(per_sequence)


loss_and_grad = value_and_grad(loss)

    Each head scores pairs of positions with a matrix product. The causal mask is applied before softmax. Each row of the resulting weights mixes the visible value vectors.

    def attention(x, wq, wk, wv, wo, causal):
  """Causal self-attention over one sequence: x is (T, C)."""
  head_width = x.shape[1] // N_HEAD
  q, k, v = x @ wq, x @ wk, x @ wv
  out = x * 0.0
  for h in range(N_HEAD):
    lo, hi = h * head_width, (h + 1) * head_width
    scores = q[:, lo:hi] @ k[:, lo:hi].T / np.sqrt(head_width)
    weights = softmax(np.where(causal, scores, -1e9))
    # Add this head’s contribution to the output embedding.
    out = out + (weights @ v[:, lo:hi]) @ wo[lo:hi]
  return out

    value_and_grad(loss) compiles the loss and its reverse pass. The gradient has the same nested tuple structure as params. Adam carries a first moment m and a second moment v for each parameter across steps.

    def train_step(params, m, v, step, tokens, targets, causal):
  value, grads = loss_and_grad(params, tokens, targets, causal)
  params, m, v = adam(params, grads, m, v, step)
  return value, params, m, v

    The runnable example uses Python for Adam. The separate CUDA benchmark keeps parameters on the GPU and compiles Adam into the training step. Complete training example · GPU benchmark · Colab training results.

    Gaussian kernel regression¶

    Predict each query's value by weighting the reference values by distance. The maximum, weight sum and weighted output can be updated a tile at a time. This is also the reduction at the heart of softmax attention.

    @parakeet.jit
def rbf_kernel_regression(x_query, x_train, y_train, neg_gamma):
  d2 = np.sum((x_query[:, None, :] - x_train[None, :, :]) ** np.float32(2.0), axis=-1)
  s = d2 * neg_gamma
  e = np.exp(s - np.max(s, axis=-1, keepdims=True))
  return (e / np.sum(e, axis=-1, keepdims=True)) @ y_train

    Histograms and tree splits¶

    Accumulate gradients and Hessians into the same bins. When their index expressions agree, the compiler can combine the two histogram traversals. Prefix sums then give the score for each possible split.

    @parakeet.jit
def gbdt_best_split(bin_ids, grads, hess, nbins, reg_lambda):
  """Return the split bin with the highest gain and the gain at that bin."""
  g_hist = dsl.iscatter(nbins, bin_ids, grads)
  h_hist = dsl.iscatter(nbins, bin_ids, hess)
  g_left = np.cumsum(g_hist)
  h_left = np.cumsum(h_hist)
  g_tot = g_left[nbins - 1]
  h_tot = h_left[nbins - 1]
  g_right = g_tot - g_left
  h_right = h_tot - h_left
  gain = (g_left * g_left) / (h_left + reg_lambda) + (g_right * g_right) / (h_right + reg_lambda)
  best_bin = np.argmax(gain)
  return best_bin, gain[best_bin]

    Min-plus matrix product¶

    Replace multiplication with addition and addition with minimum. Each output cell takes the cheapest two-leg path through an intermediate vertex. For an m × k matrix and a k × n matrix, the result has shape m × n. The indexed reduction avoids an m × n × k temporary.

    @parakeet.jit
def tropical_min_plus(a, b):
  """One min-plus matrix product: C[i,j] = min_k (A[i,k] + B[k,j])."""

  def cheapest_path(cell):
    source, destination = cell

    def through(via):
      return a[source, via] + b[via, destination]

    return dsl.ireduce(through, a.shape[1], combine=parakeet.minimum)

  return dsl.imap(cheapest_path, (a.shape[0], b.shape[1]))

    Attention and linear cross-entropy¶

    Both computations can normalize scores over tiles. In attention, the running state includes the weighted value vector. Cross-entropy needs the log normalizer and the target score. The backward pass can recompute the scores from the inputs.

    @parakeet.jit
def causal_flash_attention(q, k, v):
  T = q.shape[-2]
  idx = np.arange(T)
  mask = idx[:, None] >= idx[None, :]
  scale = np.float32(1.0 / np.sqrt(np.float32(q.shape[-1])))
  s = np.where(mask, np.matmul(q, np.swapaxes(k, -1, -2)) * scale, np.float32(-1e9))
  e = np.exp(s - np.max(s, axis=-1, keepdims=True))
  return np.matmul(e / np.sum(e, axis=-1, keepdims=True), v)

    def cut_cross_entropy(h, w, targets):
  logits = h @ w
  m = np.max(logits, axis=-1, keepdims=True)
  z = logits - m
  lse = np.log(np.sum(np.exp(z), axis=-1))
  picked = z[np.arange(h.shape[0]), targets]
  return -np.mean(picked - lse)

    For a sliding window, restrict the mask to keys within the window. When the mask and fill permit it, whole tiles can be skipped. Algebraic laws.

    Shared keys and compressed attention¶

    DeepSeek's multi-head latent attention writes expanded keys and values as matrix products. When the shape makes it cheaper, the compiler reassociates these products to operate on compressed values. Grouped-query attention shares keys and values across several query heads.

    @parakeet.jit
def deepseek_mla(q, c_kv, w_uk, w_uv):
  k = c_kv @ w_uk
  v = c_kv @ w_uv
  scale = np.float32(1.0 / np.sqrt(np.float32(q.shape[-1])))
  s = (q @ k.T) * scale
  e = np.exp(s - np.max(s, axis=-1, keepdims=True))
  return (e / np.sum(e, axis=-1, keepdims=True)) @ v

    @parakeet.jit
def gqa_attention(q, k, v):
  # q: (B, H_kv, G, T_q, D), k, v: (B, H_kv, 1, T_kv, D)
  scale = np.float32(1.0 / np.sqrt(np.float32(q.shape[-1])))
  s = np.matmul(q, np.swapaxes(k, -1, -2)) * scale
  e = np.exp(s - np.max(s, axis=-1, keepdims=True))
  return np.matmul(e / np.sum(e, axis=-1, keepdims=True), v)

    Affine scans and state-space models¶

    Two successive affine updates have an affine composition. A block of updates can summarize its effect on the incoming state, then blocks can combine their summaries in sequence order. The scalar filter and matrix-state recurrence below expose two uses of this rule.

    @parakeet.jit
def iir_exponential_filter(a, b):
  T = a.shape[0]
  out = np.empty_like(b)
  s = np.float32(0.0)
  for t in range(T):
    s = a[t] * s + b[t]
    out[t] = s
  return out

    @parakeet.jit
def mamba2_ssd(q, k, v, a):
  T = q.shape[0]
  out = np.empty((T, v.shape[1]), dtype=np.float32)
  S = np.zeros((k.shape[1], v.shape[1]), dtype=np.float32)
  for t in range(T):
    S = a[t] * S + k[t][:, None] * v[t][None, :]
    out[t] = q[t] @ S
  return out
