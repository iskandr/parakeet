    Kernel gallery¶

    These examples compile ordinary NumPy functions and explicit data-parallel operators. Each code sample comes from the runnable gallery. From an installed source checkout, run the examples and their numerical checks with:

    python examples/algebraic_gallery.py

    The examples use import numpy as np, import parakeet and from parakeet import dsl. The same @parakeet.jit compiles both ordinary NumPy and explicit operators such as dsl.map. The name dsl.kernel is an alias for parakeet.jit. Browse the source.

    Exact nearest neighbor¶

    Find the closest reference row for each query. The outer map assigns one output per query. The inner map computes distances, and argmin returns the first reference index at the minimum.

    @parakeet.jit
def exact_1nn(x_query, x_ref):
  """Exact nearest-neighbor index per query row."""
  return dsl.map(
    lambda q: np.argmin(dsl.map(lambda r: np.sum((q - r) ** np.float32(2.0)), x_ref)),
    x_query,
  )

    The CPU compiler fuses the score and reduction in both this form and its broadcast NumPy equivalent. At 1,024 queries by 4,096 references, each active query strip needs an 8 KiB tile and 192 bytes of row summaries. The GPU fold developed after 1.0.0 shares each score tile within a thread block and writes one winning distance and index per query and reference tile. Both source forms run on CUDA and Metal. Release and follow-up measurements.

    Gaussian kernel regression¶

    Predict each query's value by weighting the reference values by distance. The maximum, weight sum and weighted output can be updated a tile at a time. This is also the reduction at the heart of softmax attention.

    @parakeet.jit
def rbf_kernel_regression(x_query, x_train, y_train, neg_gamma):
  d2 = np.sum((x_query[:, None, :] - x_train[None, :, :]) ** np.float32(2.0), axis=-1)
  s = d2 * neg_gamma
  e = np.exp(s - np.max(s, axis=-1, keepdims=True))
  return (e / np.sum(e, axis=-1, keepdims=True)) @ y_train

    Histograms and tree splits¶

    Accumulate gradients and Hessians into the same bins. When their index expressions agree, the compiler can combine the two histogram traversals. Prefix sums then give the score for each possible split.

    @parakeet.jit
def gbdt_best_split(bin_ids, grads, hess, nbins, reg_lambda):
  """Histogram scatter-add + prefix sums + argmax gain in 8 lines (XGBoost/LightGBM core)."""
  g_hist = dsl.iscatter(nbins, bin_ids, grads)
  h_hist = dsl.iscatter(nbins, bin_ids, hess)
  g_left = np.cumsum(g_hist)
  h_left = np.cumsum(h_hist)
  g_tot = g_left[nbins - 1]
  h_tot = h_left[nbins - 1]
  g_right = g_tot - g_left
  h_right = h_tot - h_left
  gain = (g_left * g_left) / (h_left + reg_lambda) + (g_right * g_right) / (h_right + reg_lambda)
  best_bin = np.argmax(gain)
  return best_bin, gain[best_bin]

    Min-plus matrix product¶

    Replace multiplication with addition and addition with minimum. Each output cell takes the cheapest two-leg path through an intermediate vertex. For an m × k matrix and a k × n matrix, the result has shape m × n. The indexed reduction avoids an m × n × k temporary.

    @parakeet.jit
def tropical_min_plus(a, b):
  """One min-plus matrix product: C[i,j] = min_k (A[i,k] + B[k,j])."""
  m, n = a.shape[0], b.shape[1]
  k = a.shape[1]
  return dsl.imap(
    lambda ij: dsl.ireduce(lambda r: a[ij[0], r] + b[r, ij[1]], k, combine=parakeet.minimum),
    (m, n),
  )

    Attention and linear cross-entropy¶

    Both computations can normalize scores over tiles. In attention, the running state includes the weighted value vector. Cross-entropy needs the log normalizer and the target score. The backward pass can recompute the scores from the inputs.

    @parakeet.jit
def causal_flash_attention(q, k, v):
  T = q.shape[-2]
  idx = np.arange(T)
  mask = idx[:, None] >= idx[None, :]
  scale = np.float32(1.0 / np.sqrt(np.float32(q.shape[-1])))
  s = np.where(mask, np.matmul(q, np.swapaxes(k, -1, -2)) * scale, np.float32(-1e9))
  e = np.exp(s - np.max(s, axis=-1, keepdims=True))
  return np.matmul(e / np.sum(e, axis=-1, keepdims=True), v)

    def cut_cross_entropy(h, w, targets):
  logits = h @ w
  m = np.max(logits, axis=-1, keepdims=True)
  z = logits - m
  lse = np.log(np.sum(np.exp(z), axis=-1))
  picked = z[np.arange(h.shape[0]), targets]
  return -np.mean(picked - lse)

    For a sliding window, restrict the mask to keys within the window. When the mask and fill permit it, whole tiles can be skipped. Algebraic laws.

    Shared keys and compressed attention¶

    DeepSeek's multi-head latent attention writes expanded keys and values as matrix products. When the shape makes it cheaper, the compiler reassociates these products to operate on compressed values. Grouped-query attention shares keys and values across several query heads.

    @parakeet.jit
def deepseek_mla(q, c_kv, w_uk, w_uv):
  k = c_kv @ w_uk
  v = c_kv @ w_uv
  scale = np.float32(1.0 / np.sqrt(np.float32(q.shape[-1])))
  s = (q @ k.T) * scale
  e = np.exp(s - np.max(s, axis=-1, keepdims=True))
  return (e / np.sum(e, axis=-1, keepdims=True)) @ v

    @parakeet.jit
def gqa_attention(q, k, v):
  # q: (B, H_kv, G, T_q, D), k, v: (B, H_kv, 1, T_kv, D)
  scale = np.float32(1.0 / np.sqrt(np.float32(q.shape[-1])))
  s = np.matmul(q, np.swapaxes(k, -1, -2)) * scale
  e = np.exp(s - np.max(s, axis=-1, keepdims=True))
  return np.matmul(e / np.sum(e, axis=-1, keepdims=True), v)

    Affine scans and state-space models¶

    Two successive affine updates have an affine composition. A block of updates can summarize its effect on the incoming state, then blocks can combine their summaries in sequence order. The scalar filter and matrix-state recurrence below expose two uses of this rule.

    @parakeet.jit
def iir_exponential_filter(a, b):
  T = a.shape[0]
  out = np.empty_like(b)
  s = np.float32(0.0)
  for t in range(T):
    s = a[t] * s + b[t]
    out[t] = s
  return out

    @parakeet.jit
def mamba2_ssd(q, k, v, a):
  T = q.shape[0]
  out = np.empty((T, v.shape[1]), dtype=np.float32)
  S = np.zeros((k.shape[1], v.shape[1]), dtype=np.float32)
  for t in range(T):
    S = a[t] * S + k[t][:, None] * v[t][None, :]
    out[t] = q[t] @ S
  return out

    Inspect a rewrite¶

    Pass example arrays to the inspector to see which laws fired and compare the operator IR before and after compilation. This example uses the Gaussian regression function above.

    rng = np.random.default_rng(0)
q = rng.standard_normal((64, 8), dtype=np.float32)
x = rng.standard_normal((256, 8), dtype=np.float32)
y = rng.standard_normal((256, 4), dtype=np.float32)
print(dsl.show_rewrite(rbf_kernel_regression, q, x, y, np.float32(-1)))
