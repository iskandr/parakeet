    ¶

    A data-parallel compiler for numerical Python.

    Write ordinary NumPy, loops, comprehensions, or explicit data-parallel operators (map, reduce, scan, allpairs). Parakeet specializes your function for its input types, fuses and tiles the array algebra, and compiles native code for multi-core CPUs, Apple Metal, and NVIDIA CUDA.

    Exact nearest neighbor¶

    import numpy as np
from parakeet import jit


@jit
def nearest(x, y):
  delta = x[:, None, :] - y[None, :, :]
  d2 = np.sum(delta ** np.float32(2), axis=2)
  return np.argmin(d2, axis=1)

    Parakeet computes distances a tile at a time on both CPU and GPU, keeping only the winning reference index per tile rather than allocating the full N × M distance matrix. Ties preserve NumPy's first-index rule.

    Install¶

    python -m pip install parakeet

    Requires Python 3.11+, NumPy 2, and a system C compiler. For GPU backends, install parakeet[metal] on Apple Silicon or parakeet[cuda12] with an NVIDIA GPU.

    One algebra underneath¶

    Since its beginnings in 2012, Parakeet has been built on a simple observation: most numerical Python — whether written as NumPy expressions, comprehensions, or explicit parallel operators — expresses the same handful of array computations: maps, reductions, scans, filters, and scatters.

    @jit
def scaled_tanh_numpy(x, alpha=0.5, beta=0.3):
  return np.tanh(x * alpha) + beta


@jit
def scaled_tanh_comp(x, alpha=0.5, beta=0.3):
  return np.array([np.tanh(xi * alpha) + beta for xi in x])

    Both lower to the same single fused parallel loop with no temporary arrays. Keeping that operator algebra intact through the middle end lets a small set of general passes do the heavy lifting:

    • Fusion. Chained array expressions, filtered reductions (np.sum(x[x > 0])), and sibling histograms sharing the same bin IDs merge into one pass. See the tree-split example.
    • Tiling and single-pass reductions. Associative reductions and bilinear products tile into cache or GPU shared memory, so Gaussian kernel regression, nearest-neighbor search, and attention stream blocks instead of allocating giant pairwise matrices. Read the algebraic laws.
    • Gradients. parakeet.grad and parakeet.value_and_grad differentiate the array operators directly, compiling a training step into one native function. Learn about gradients.
    • Inspection. Every stage is visible: inspect the operator IR, see which rewrites fired with parakeet.dsl.show_rewrite, or read the generated C, Metal, or CUDA source. Inspect a rewrite.
