    Bioinformatics & structural biology¶

    Scientific computing in genomics, cheminformatics, and structural biology is full of kernels that do not fit standard dense GEMM libraries: byte-level FASTQ parsing and 2-bit k-mer packing, multi-channel alignment pileups, 2048-bit chemical fingerprint screening, 3D protein coordinate message passing, and banded dynamic programming alignments.

    Parakeet compiles these workloads directly from concise NumPy and data-parallel operators into fused, multi-core CPU and GPU code; without hand-writing C, CUDA, or Metal.

    Every snippet below is included from examples/bio_gallery.py. Run the gallery checks or reproducible benchmarks from a source checkout:

    python -m examples.bio_gallery
python benchmarks/bio_workloads.py

    How algebraic primitives map to bio workloads¶

    Domain task Operator / optimization in Parakeet What the compiler eliminates
    FASTQ k-mers & read QC par.map (multi-output) + IntEnum + ASCII-dict LUT Explicit parfor, manual np.empty buffers, and ASCII bit-twiddling
    Multi-channel BAM pileup Keyed IndexScatter fusion Redundant passes over alignment positions (6 -> 1)
    Chemical fingerprint screening par.popcount + par.allpairs + ordered par.fold (pairwise_fold) O(N · M) similarity matrix allocation
    3D protein RBF / equivariant attention Online rescaled-monoid tiling + par.grad O(N²) pairwise distance & weight matrices
    Banded Smith-Waterman & genome SSMs Two-row banded DP + chunkwise affine prefix scan (TileScan) Python DP interpreter overhead & sequential scan bottlenecks

    1. FASTQ 2-bit canonical k-mers and read QC¶

    Parakeet accepts list[str] directly (packing equal-length strings into a 2D uint8 array or variable-length strings into a RaggedArray[uint8]), compiles constant single-character dictionaries (BASE_CODE) into 256-byte lookup tables, supports IntEnum alphabets (Base.A, Base.C, Base.G, Base.T), and unboxes multi-output par.map tuples into one parallel pass:

    class Base(IntEnum):
  A = 0
  C = 1
  G = 2
  T = 3


BASE_CODE = {"A": Base.A, "C": Base.C, "G": Base.G, "T": Base.T}


@par.jit
def encode_canonical_kmers_and_gc(reads, quals, k):
  """Encode ASCII DNA reads (``list[str]`` or ``(N, L)`` uint8) into:
  - canonical 2-bit k-mers ``(N, L - k + 1)`` uint64  [min(fwd, revcomp)]
  - per-read GC fraction ``(N,)`` float32
  - per-read mean Phred quality ``(N,)`` float32
  """
  mask = (~np.uint64(0)) >> np.uint64(64 - 2 * k)
  rev_shift = np.uint64(2 * (k - 1))

  def encode_read(seq, qual):
    codes = BASE_CODE[seq]
    gc = np.mean((codes == Base.C) | (codes == Base.G)).astype(np.float32)
    mean_q = np.mean(qual.astype(np.float32) - 33.0)
    out = np.empty(len(seq) - k + 1, dtype=np.uint64)
    fwd = np.uint64(0)
    rev = np.uint64(0)
    for pos, c in enumerate(codes):
      code = np.uint64(c)
      fwd = ((fwd << np.uint64(2)) | code) & mask
      rev = (rev >> np.uint64(2)) | ((np.uint64(3) ^ code) << rev_shift)
      if pos >= k - 1:
        out[pos - k + 1] = min(fwd, rev)
    return out, gc, mean_q

  return par.map(encode_read, reads, quals)

    2. Single-pass multi-channel alignment pileup¶

    A pileup records A/C/G/T base counts, Phred quality sums, and reverse-strand counts at each reference coordinate. Because all six par.scatter_add updates share the same index array ref_pos, Parakeet's scatter-fusion pass combines them into a single privatized traversal (IndexScatter: 6 -> 1):

    @par.jit
def single_pass_pileup(ref_pos, base_code, phred_q, is_rev, contig_len):
  """Accumulate A/C/G/T counts, quality sums, and reverse-strand counts across
  aligned base observations in one keyed IndexScatter traversal."""
  # All six histograms share `ref_pos` -> Parakeet fuses them into ONE traversal.
  cnt_a = par.scatter_add(contig_len, ref_pos, (base_code == Base.A).astype(np.int64))
  cnt_c = par.scatter_add(contig_len, ref_pos, (base_code == Base.C).astype(np.int64))
  cnt_g = par.scatter_add(contig_len, ref_pos, (base_code == Base.G).astype(np.int64))
  cnt_t = par.scatter_add(contig_len, ref_pos, (base_code == Base.T).astype(np.int64))
  qual_sum = par.scatter_add(contig_len, ref_pos, phred_q.astype(np.int64))
  rev_cnt = par.scatter_add(contig_len, ref_pos, is_rev.astype(np.int64))
  return cnt_a, cnt_c, cnt_g, cnt_t, qual_sum, rev_cnt

    3. 2048-bit Morgan fingerprint Tanimoto screening¶

    Chemical similarity screening compares query fingerprints (N, 32) against a compound library (M, 32) of packed uint64 bitvectors (2,048 bits each). Combining par.popcount with par.allpairs and an ordered par.fold finds the closest library compound per query while preserving first-index ties:

    class BestHit(NamedTuple):
  sim: np.float32
  index: np.int64


def better_hit(left, right):
  # Highest Tanimoto similarity wins; ties preserve the first library compound.
  return right if right.sim > left.sim else left


@par.jit
def tanimoto_nearest_hit(queries, library):
  """Find the closest library compound per query over packed uint64 fingerprints
  (N, W) x (M, W) using tiled pairwise folds with zero N x M allocation."""
  pop_q = np.sum(par.popcount(queries), axis=1)
  pop_l = np.sum(par.popcount(library), axis=1)

  inter = par.allpairs(lambda q_row, l_row: np.sum(par.popcount(q_row & l_row)), queries, library)
  denom = pop_q[:, None] + pop_l[None, :] - inter
  sim = np.where(denom > 0, inter.astype(np.float32) / np.maximum(denom, 1).astype(np.float32), np.float32(0.0))
  return par.fold(BestHit, better_hit, sim, axis=1, indexed=True, emit=lambda hit: hit.index)

    4. 3D protein coordinate RBF message passing¶

    Pairwise radial-basis-function smoothing over 3D residue coordinates (N, 3) uses the same rescaled-monoid structure as softmax attention. Online monoidal tiling fuses the squared-distance computation, softmax normalization, and feature aggregation into a single tiled pass with zero O(N²) score allocation; and par.grad differentiates through the 3D coordinates directly:

    @par.jit
def protein_rbf_message_passing(coords, features, neg_inv_2sigma2):
  """3D radial-basis-function message passing over residue coordinates (N, 3).

  Fuses into online (m, l, O) monoidal tiles with zero N x N materialization.
  """
  d2 = np.sum((coords[:, None, :] - coords[None, :, :]) ** np.float32(2.0), axis=-1)
  s = d2 * neg_inv_2sigma2
  e = np.exp(s - np.max(s, axis=-1, keepdims=True))
  return (e / np.sum(e, axis=-1, keepdims=True)) @ features


def protein_rbf_loss(coords, features, targets, neg_inv_2sigma2):
  pred = protein_rbf_message_passing(coords, features, neg_inv_2sigma2)
  diff = pred - targets
  return np.mean(diff * diff)


protein_coord_grad = par.grad(protein_rbf_loss, argnum=0)

    5. Banded Smith-Waterman alignment and DNA state-space scan¶

    Compiled two-row banded Smith-Waterman keeps only O(M) score scratch in L1 cache, while 1D DNA exponential state-space recurrences automatically rewrite into chunkwise parallel affine prefix scans (TileScan):

    @par.jit
def banded_smith_waterman(seq_a, seq_b, match_score, mismatch_pen, gap_pen, band_width):
  """Banded Smith-Waterman local alignment score over sequences.

  Keeps only two O(M) score rows in cache and restricts columns to |j - i| <= band_width.
  """
  n, m = len(seq_a), len(seq_b)
  prev = np.zeros(m + 1, dtype=np.float32)
  curr = np.zeros(m + 1, dtype=np.float32)
  best = np.float32(0.0)
  for i in range(1, n + 1):
    ai = seq_a[i - 1]
    j_lo = max(1, i - band_width)
    j_hi = min(m, i + band_width)
    for j in range(j_lo, j_hi + 1):
      sub = match_score if ai == seq_b[j - 1] else mismatch_pen
      v = max(np.float32(0.0), prev[j - 1] + sub, prev[j] + gap_pen, curr[j - 1] + gap_pen)
      curr[j] = v
      best = max(best, v)
    prev[j_lo : j_hi + 1] = curr[j_lo : j_hi + 1]
    curr[j_lo : j_hi + 1] = 0.0
  return best


@par.jit
def dna_ssm_scan(decay, signal):
  """Exponential state-space scan along a DNA track (L,).

  Compiled via chunkwise parallel affine prefix scan (TileScan).
  """
  out = np.empty_like(signal)
  s = np.float32(0.0)
  for t in range(len(decay)):
    s = decay[t] * s + signal[t]
    out[t] = s
  return out

    6. Classic sequence & structural algorithms (examples/bio_algorithms.py)¶

    Beyond fused gallery kernels, examples/bio_algorithms.py implements seven textbook bioinformatics kernels in compiled Python/NumPy:

    • 3-state affine-gap Gotoh global alignment + traceback (gotoh_global_align): Maintains M, Ix, and Iy DP matrices plus packed traceback directions and emits run-length-encoded CIGAR (ops, lengths) via local growable lists.
    • Multi-word Myers bit-vector edit distance (myers_edit_distance): Bit-parallel Levenshtein distance over arbitrary pattern lengths using 64-bit uint64 word blocks (Pv, Mv, Peq).
    • O(N) monotone-deque minimizer sketching (minimizer_sketch): Canonical 2-bit k-mers hashed with SplitMix64 and sketched in a single linear pass using a circular monotone deque.
    • FM-index / BWT backward search (build_fm_index, fm_backward_search_batch): C array + sampled Occ checkpoints + LF-mapping queried in parallel over a RaggedArray[uint8] batch of reads.
    • CIGAR expansion (expand_cigar): One-line parallel expansion of (ops, lengths) via par.flatmap (IndexExpand).
    • Profile HMM Viterbi + Forward-Backward (hmm_viterbi_and_posterior): Log-space Viterbi decoding plus Forward-Backward posterior state probabilities.
    • Kabsch 3D superposition & RMSD (kabsch_rmsd, batched_kabsch_rmsd): Uses Parakeet's compiled np.linalg.svd and np.linalg.det (with proper rotation reflection correction when det(R) < 0) inside par.parfor to superimpose thousands of protein structures in parallel with zero external LAPACK dependency.

    7. Long-read RNA alignment & quantification (examples/patro_longread_rna.py)¶

    Inspired by Rob Patro's COMBINE lab tools (SSHash, Piscem, Spearfish, and Oarfish), examples/patro_longread_rna.py puts a complete long-read RNA aligner and isoform quantifier into ~250 lines of compiled Python/NumPy:

    1. Unitig collapse + SSHash sparse minimizer index (build_unitig_sshash_index): Collapses redundant gene isoforms into exact maximal shared unitigs stored in CSR arrays with unitig -> (tx_id, tx_pos) postings and a FrozenHashTable mapping sparse m-mer minimizers to small unitig buckets.
    2. Streaming unitig contiguity + Spearfish delta-mapping (stream_map_long_reads): Inside par.parfor over a RaggedArray[uint8] of long reads, once a minimizer probe lands on a unitig, the inner loop extends the Maximal Exact Match (MEM) along that unitig in O(1) per base with zero hash lookups, projects the anchor to all sharing isoforms via CSR postings, chains co-linear diagonals, and retains competitive isoforms within delta_frac of the top score.
    3. Oarfish-style coverage-aware EM (oarfish_em_quantify): Runs compiled Expectation-Maximization over the delta-mapped compatibility sets, weighting each compatible isoform by alignment score and effective length compatibility.

    On 80 real human Ensembl cDNA isoforms (TP53, PKM, MAPT, ACTB; 225,539 raw bp), unitig collapsing shrinks the reference by 9.7x (23,247 unitig bp across 231 unitigs), the SSHash fast path skips the hash table on 92.2% of base steps, multicore mapping sustains 548.6 Mbp/s on Apple M1 Pro (11-replicate median), and Oarfish EM achieves Pearson r = 0.965 against ground truth.

    8. Overlapped CPU I/O, decompression, and compiler scope¶

    Parakeet intentionally does not embed POSIX file descriptors, zlib/zstd container parsers, or streaming I/O syscalls inside @par.jit. Keeping I/O out of whole-program compilation keeps the compiler small, portable, and GPU-safe, while still allowing full overlap between disk/codec work and compute:

    Double-buffered CPU I/O + kernel orchestration¶

    Compiled Parakeet functions release the Python GIL for their entire C, multicore, CUDA, or Metal execution. That makes overlapped streaming straightforward with a 2-slot (or N-slot) ring buffer:

    1. Producer thread (ThreadPoolExecutor / background reader): Reads raw FASTQ/BAM chunks from disk or mmap, decompresses them with a fast native codec (isal, zlib-ng, libdeflate, or pysam), and packs the next slab into a pre-allocated pinned uint8 / RaggedArray host buffer (and on GPU, stages an asynchronous host-to-device copy onto slot k % 2).
    2. Consumer thread (Parakeet compute): Launches @par.jit kernels (e.g., par.split_bytes, encode_canonical_kmers_and_gc, stream_map_long_reads, or single_pass_pileup) on slab (k - 1) % 2. Because the GIL is released, CPU decompression of slab k overlaps directly with multicore/GPU kernels crunching slab k - 1.
    3. Thread budget coordination: On CPU-only hosts, reserve 1-2 cores for the decompression producer and cap Parakeet's worker pool (PARAKEET_THREADS) to the remaining cores so reader and compute threads do not oversubscribe.

    What belongs in Parakeet vs. outside its semantic hull¶

    • Fits inside @par.jit: Block-parallel BGZF DEFLATE inflate. Because BGZF splits .bam / .fastq.gz files into independent <= 64 KiB compressed blocks whose uncompressed sizes (ISIZE) are known up front from the block headers, examples/bgzf_and_streaming_io.py compiles a full RFC-1951 DEFLATE inflater (stored, fixed Huffman, and dynamic Huffman with a 9-bit fast LUT + LZ77) in pure Python across all BGZF blocks in parallel, alongside a double-buffered overlapped zlib + Parakeet FASTQ pipeline. On 20,000 FASTQ reads (6.31 MB raw / 3.16 MB BGZF, 97 blocks) on Apple M1 Pro:
    • Raw inflate: Python gzip (C zlib 1T) 226 MB/s vs. Parakeet BGZF 1T 203 MB/s vs. Parakeet BGZF multicore 1,579 MB/s (7.0x faster).
    • End-to-end decompress + FASTQ QC: sequential gzip + QC 168 MB/s vs. overlapped double-buffered zlib + QC 341 MB/s (2.0x) vs. Parakeet parallel BGZF + QC 906 MB/s (5.4x).
    • Escapes Parakeet's semantic hull: Single-stream sequential gzip/zstd decompression, container framing/CRC error recovery, file I/O syscalls, and unbounded dynamic output growth on GPU. Single-stream DEFLATE has a serial 32 KiB sliding-window dependency with no data parallelism, and native SIMD/assembly libraries (isa-l, libdeflate, zstd) already saturate NVMe bandwidth on 1-2 CPU cores. Feed decompressed uint8 slabs from those libraries into Parakeet instead.

    Inspecting the rewrites¶

    Run par.show_rewrite on any workload above to verify that scatter fusion, online monoidal tiling, or chunkwise parallel scans fired:

    import numpy as np
import parakeet as par
from examples.bio_gallery import single_pass_pileup, protein_rbf_message_passing

pos = np.zeros(10_000, np.int64)
u8 = np.zeros(10_000, np.uint8)
print(par.show_rewrite(single_pass_pileup, pos, u8, u8, u8, 4096).summary())

coords = np.zeros((128, 3), np.float32)
feats = np.zeros((128, 16), np.float32)
print(par.show_rewrite(protein_rbf_message_passing, coords, feats, np.float32(-0.05)).summary())
