    Bioinformatics & structural biology¶

    Genomics, cheminformatics, and structural biology are full of kernels that do not fit standard dense GEMM libraries: byte-level FASTQ parsing, 2-bit k-mer packing, multi-channel pileups, 2048-bit fingerprint screening, 3D protein message passing, and banded dynamic programming. Parakeet compiles all of them directly from concise Python and NumPy into multi-core CPU and GPU code.

    Every snippet below is included verbatim from examples/bio_gallery.py. Run the examples or benchmarks from a checkout:

    python -m examples.bio_gallery
python benchmarks/bio_workloads.py

    Categorical encoding for sequences and tokens¶

    Working with character sequences in compiled code—whether DNA bases (ACGT), amino acids, GC indicator masks, or text tokens for a language model—comes down to the same operation: mapping ASCII bytes to compact integer codes through a 256-entry lookup table.

    Rather than defining an IntEnum and a separate dict mapping characters to enum members, Parakeet provides two lightweight categorical encoders:

    • par.Alphabet("ACGT") maps ASCII characters to uint8 codes 0..3 (case-insensitive by default), and par.Alphabet.mask("GC") builds a 0/1 indicator table. Both work outside @par.jit (DNA.encode(reads)) and inside @par.jit (DNA[seq], GC[seq]), compiling to a single L1-resident 256-byte gather.
    • par.Vocab.from_text(text) builds the same 256-entry LUT from a text corpus for language-model tokenization (vocab.encode(text) / vocab.decode(ids)), as shown in Train nanoGPT.

    How Parakeet compiles bio workloads¶

    Domain task Operators & compiler passes What is eliminated
    FASTQ k-mers & read QC Multi-output par.map + par.Alphabet LUT Manual parfor, scratch buffers, and ASCII bit-twiddling
    Multi-channel BAM pileup Keyed IndexScatter fusion Redundant passes over alignment positions (6 → 1)
    2048-bit Tanimoto screening par.popcount + par.allpairs + ordered par.fold O(N · M) similarity matrix allocation
    3D protein RBF message passing Law 1 monoidal tiling + par.grad O(N²) pairwise distance & weight matrices
    Banded Smith-Waterman & DNA SSM Two-row banded DP + Law 4 chunkwise scan Python DP interpreter overhead & serial scan bottlenecks

    1. FASTQ 2-bit canonical k-mers and read QC¶

    Parakeet accepts list[str] directly (packing fixed-length strings into 2D uint8 or variable-length strings into RaggedArray[uint8]), compiles DNA[seq] and GC[seq] to 256-byte LUT gathers, and unboxes multi-output par.map tuples into one parallel pass:

    DNA = par.Alphabet("ACGT")
GC = par.Alphabet.mask("GC")
A, C, G, T = (DNA.code(b) for b in "ACGT")


@par.jit
def encode_canonical_kmers_and_gc(reads, quals, k):
  """Encode ASCII DNA reads (``list[str]`` or ``(N, L)`` uint8) into:
  - canonical 2-bit k-mers ``(N, L - k + 1)`` uint64  [min(fwd, revcomp)]
  - per-read GC fraction ``(N,)`` float32
  - per-read mean Phred quality ``(N,)`` float32
  """
  mask = (~np.uint64(0)) >> np.uint64(64 - 2 * k)
  rev_shift = np.uint64(2 * (k - 1))

  def encode_read(seq, qual):
    codes = DNA[seq]
    gc = np.mean(GC[seq].astype(np.float32))
    mean_q = np.mean(qual.astype(np.float32) - 33.0)
    out = np.empty(len(seq) - k + 1, dtype=np.uint64)
    fwd = np.uint64(0)
    rev = np.uint64(0)
    for pos, c in enumerate(codes):
      code = np.uint64(c)
      fwd = ((fwd << np.uint64(2)) | code) & mask
      rev = (rev >> np.uint64(2)) | ((np.uint64(3) ^ code) << rev_shift)
      if pos >= k - 1:
        out[pos - k + 1] = min(fwd, rev)
    return out, gc, mean_q

  return par.map(encode_read, reads, quals)

    2. Single-pass multi-channel alignment pileup¶

    All six par.scatter_add channels (A/C/G/T counts, Phred quality sum, reverse strand count) share ref_pos, so scatter fusion merges them into one thread-privatized pass (IndexScatter: 6 → 1):

    @par.jit
def single_pass_pileup(ref_pos, base_code, phred_q, is_rev, contig_len):
  """Accumulate A/C/G/T counts, quality sums, and reverse-strand counts across
  aligned base observations in one keyed IndexScatter traversal."""
  # All six histograms share ref_pos, so Parakeet fuses them into one pass.
  cnt_a = par.scatter_add(contig_len, ref_pos, (base_code == A).astype(np.int64))
  cnt_c = par.scatter_add(contig_len, ref_pos, (base_code == C).astype(np.int64))
  cnt_g = par.scatter_add(contig_len, ref_pos, (base_code == G).astype(np.int64))
  cnt_t = par.scatter_add(contig_len, ref_pos, (base_code == T).astype(np.int64))
  qual_sum = par.scatter_add(contig_len, ref_pos, phred_q.astype(np.int64))
  rev_cnt = par.scatter_add(contig_len, ref_pos, is_rev.astype(np.int64))
  return cnt_a, cnt_c, cnt_g, cnt_t, qual_sum, rev_cnt

    3. 2048-bit Morgan fingerprint Tanimoto screening¶

    Compares query fingerprints (N, 32) against a library (M, 32) of packed uint64 bitvectors using par.popcount, par.allpairs, and an ordered par.fold (preserving first-index ties without allocating an N × M matrix):

    class BestHit(NamedTuple):
  sim: np.float32
  index: np.int64


def better_hit(left, right):
  # Highest Tanimoto similarity wins; ties preserve the first library compound.
  return right if right.sim > left.sim else left


@par.jit
def tanimoto_nearest_hit(queries, library):
  """Find the closest library compound per query over packed uint64 fingerprints
  (N, W) x (M, W) using tiled pairwise folds with zero N x M allocation."""
  pop_q = np.sum(par.popcount(queries), axis=1)
  pop_l = np.sum(par.popcount(library), axis=1)

  inter = par.allpairs(lambda q_row, l_row: np.sum(par.popcount(q_row & l_row)), queries, library)
  denom = pop_q[:, None] + pop_l[None, :] - inter
  sim = np.where(denom > 0, inter.astype(np.float32) / np.maximum(denom, 1).astype(np.float32), np.float32(0.0))
  return par.fold(BestHit, better_hit, sim, axis=1, indexed=True, emit=lambda hit: hit.index)

    4. 3D protein coordinate RBF message passing¶

    Pairwise radial-basis-function smoothing over 3D residue coordinates (N, 3) uses the same rescaled-monoid tiling as softmax attention—zero O(N²) buffers and directly differentiable through par.grad:

    @par.jit
def protein_rbf_message_passing(coords, features, neg_inv_2sigma2):
  """3D radial-basis-function message passing over residue coordinates (N, 3).

  Fuses into online (m, l, O) monoidal tiles with zero N x N materialization.
  """
  d2 = np.sum((coords[:, None, :] - coords[None, :, :]) ** np.float32(2.0), axis=-1)
  s = d2 * neg_inv_2sigma2
  e = np.exp(s - np.max(s, axis=-1, keepdims=True))
  return (e / np.sum(e, axis=-1, keepdims=True)) @ features


def protein_rbf_loss(coords, features, targets, neg_inv_2sigma2):
  pred = protein_rbf_message_passing(coords, features, neg_inv_2sigma2)
  diff = pred - targets
  return np.mean(diff * diff)


protein_coord_grad = par.grad(protein_rbf_loss, argnum=0)

    5. Banded Smith-Waterman and DNA state-space scan¶

    Two-row banded Smith-Waterman stays in O(M) L1 scratch, while 1D DNA exponential recurrences rewrite automatically into Law 4 chunkwise parallel scans:

    @par.jit
def banded_smith_waterman(seq_a, seq_b, match_score, mismatch_pen, gap_pen, band_width):
  """Banded Smith-Waterman local alignment score over sequences.

  Keeps only two O(M) score rows in cache and restricts columns to |j - i| <= band_width.
  """
  n, m = len(seq_a), len(seq_b)
  prev = np.zeros(m + 1, dtype=np.float32)
  curr = np.zeros(m + 1, dtype=np.float32)
  best = np.float32(0.0)
  for i in range(1, n + 1):
    ai = seq_a[i - 1]
    j_lo = max(1, i - band_width)
    j_hi = min(m, i + band_width)
    for j in range(j_lo, j_hi + 1):
      sub = match_score if ai == seq_b[j - 1] else mismatch_pen
      v = max(np.float32(0.0), prev[j - 1] + sub, prev[j] + gap_pen, curr[j - 1] + gap_pen)
      curr[j] = v
      best = max(best, v)
    prev[j_lo : j_hi + 1] = curr[j_lo : j_hi + 1]
    curr[j_lo : j_hi + 1] = 0.0
  return best


@par.jit
def dna_ssm_scan(decay, signal):
  """Exponential state-space scan along a DNA track (L,).

  Compiled via chunkwise parallel affine prefix scan (TileScan).
  """
  out = np.empty_like(signal)
  s = np.float32(0.0)
  for t in range(len(decay)):
    s = decay[t] * s + signal[t]
    out[t] = s
  return out

    7. Long-read RNA alignment & quantification¶

    Inspired by Rob Patro's COMBINE lab tools (SSHash, Piscem, Spearfish, and Oarfish), examples/patro_longread_rna.py implements a full long-read RNA aligner and isoform quantifier in ~250 lines of compiled Python/NumPy:

    1. Unitig collapse + SSHash minimizer index (build_unitig_sshash_index): collapses isoforms into maximal shared unitigs in CSR arrays with a FrozenHashTable mapping sparse minimizers to unitig buckets.
    2. Streaming unitig contiguity + Spearfish delta-mapping (stream_map_long_reads): extends Maximal Exact Matches along unitigs in O(1)/base (skipping hash lookups), projects anchors to isoforms via CSR postings, chains co-linear diagonals, and keeps competitive isoforms within delta_frac.
    3. Oarfish-style coverage-aware EM (oarfish_em_quantify): compiled EM over compatibility sets weighted by alignment score and effective length.

    On 80 human Ensembl cDNA isoforms (TP53, PKM, MAPT, ACTB; 225,539 raw bp), unitig collapse shrinks the reference 9.7× (23,247 bp across 231 unitigs), the SSHash fast path skips hash probes on 92.2% of bases, multicore mapping sustains 548.6 Mbp/s on Apple M1 Pro, and Oarfish EM reaches Pearson r = 0.965 against ground truth.

    8. Streaming I/O, BGZF inflate, and compiler scope¶

    Parakeet intentionally keeps file descriptors, container framing, and streaming I/O syscalls outside @par.jit so compiled kernels stay small, portable, and GPU-safe. Because compiled functions release the Python GIL, disk/codec work overlaps cleanly with compute:

    • Double-buffered I/O + compute: a background reader thread decompresses slabs (isal, zlib-ng, libdeflate, or pysam) into pinned uint8 / RaggedArray buffers while Parakeet processes the previous slab across CPU cores or on GPU (reserve 1–2 CPU cores for the reader on CPU-only hosts via PARAKEET_NUM_THREADS).
    • Block-parallel BGZF inflate fits inside @par.jit: because BGZF splits .bam / .fastq.gz files into independent ≤ 64 KiB blocks with known uncompressed sizes, examples/bgzf_and_streaming_io.py compiles a full RFC-1951 DEFLATE inflater across all blocks in parallel. On 20,000 FASTQ reads (6.31 MB raw, 97 blocks, Apple M1 Pro):
    • Raw inflate: Python gzip (1T) 226 MB/s vs. Parakeet BGZF 1T 203 MB/s vs. Parakeet BGZF multicore 1,579 MB/s (7.0×).
    • Decompress + FASTQ QC: sequential gzip + QC 168 MB/s vs. overlapped double-buffered zlib + QC 341 MB/s (2.0×) vs. Parakeet parallel BGZF + QC 906 MB/s (5.4×).
    • Use native codecs for single-stream gzip/zstd: single-stream DEFLATE has a serial 32 KiB sliding-window dependency with no data parallelism—feed decompressed uint8 slabs from isa-l/libdeflate/zstd into Parakeet.
